Quick Setup Guide

1. Create a Telegram bot using @BotFather.
2. Enter the bot token and your Telegram chat ID.
3. Save the credentials and test the connection.
4. Click Upload Data to create a JSON backup and separately upload Speaking recordings.
5. Telegram credentials are never included in the JSON backup.
6. Restore downloads the JSON backup. Audio recordings remain stored separately in Telegram.
